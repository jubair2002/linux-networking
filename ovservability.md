DevOps, CI/CD & Monitoring
Objectives
- Understand DevOps culture and Git/GitHub workflows.
- Learn CI/CD practices: automated testing, builds, and deployments.
- Manage environment variables and deployment environments securely.
- Explore Docker-based deployment, application logs, and basic monitoring.
Workflow
GitHub → Build → Test → Docker → Deploy → Monitor
Outcome
Build a basic CI/CD workflow and monitor a deployed application using logs and basic observability.
